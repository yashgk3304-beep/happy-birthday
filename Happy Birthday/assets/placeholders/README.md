# Placeholder Assets

Replace the SVG files in this folder with real photos or generated artwork when you want a more personal memory reel.

Recommended image sizes:

- Memory slides: 1600 x 1067 or any 3:2 image
- Gift reveal images: 1200 x 900 or any 4:3 image
- Audio files: place optional `.mp3` or `.wav` files in `assets/audio/`
